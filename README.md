
EdTech Platform

A full-stack Learning Management System (LMS) built using Node.js, Express, and MongoDB.
This platform provides secure authentication, role-based access, and course management for students and instructors.

Features

User roles (Student / Instructor / Admin)
Course creation, update, and deletion
Student enrollment system
JWT Authentication & Authorization
Role-Based Access Control (RBAC)
User progress tracking
RESTful API architecture
Input validation using Joi
Security features (rate limiting, bcrypt password hashing)
Google OAuth authentication (Passport)
Tech Stack
Backend: Node.js, Express.js
Database: MongoDB (Mongoose)
Authentication: JWT, bcrypt, Passport (Google OAuth)
Security: express-rate-limit, cors, session
DevOps / Deployment: Docker, Docker Compose
